## Featured Projects

<a name="projects"></a>

#### AI & Automation

**[AI Email Automation Agent](https://github.com/saif098-bit/AI-Email-Automation-Agent)**
An n8n workflow that polls Gmail, classifies incoming mail as orders or inquiries with a LangChain text classifier, then drafts replies using Groq's Llama 3.1 8B — validated through a parallel Google Sheets evaluation pipeline before deployment.
`n8n` `Groq (Llama 3.1)` `LangChain` `Google Sheets`

**[AI Hotel Assistant Chatbot](https://github.com/saif098-bit/hotelbot)**
A Flask chatbot that answers hotel FAQs through fuzzy string matching against a SQLite knowledge base, falling back to a locally hosted LLM (Ollama — Phi-3/Mistral) for open-ended queries, with logging for continuous FAQ improvement.
`Python` `Flask` `SQLite` `Ollama`

#### Backend Engineering

**[Smart Medicine Inventory System](https://github.com/saif098-bit/smart-medicine-system)**
Full-stack pharmacy inventory platform with real-time dashboards for expired/low-stock items, an AI assistant chatbot (OpenAI with Groq fallback), and DSA-based visualizations (stack/queue/priority queue) — packaged as an offline-capable PWA.
`Python` `Flask` `SQLAlchemy` `SQLite` `OpenAI` `Groq`

**[Smart Attendance Management System](https://github.com/saif098-bit/Smart-Attendance-System)**
Role-based (admin/teacher/student) attendance platform with Flask-Login authentication and a PostgreSQL/SQLite backend, automating 75% attendance-eligibility enforcement with Excel and Matplotlib reporting.
`Python` `Flask` `PostgreSQL` `Pandas` `Matplotlib`

**[Cloud Order-Processing Simulator (FCFS Scheduling)](https://github.com/saif098-bit/FCFS-Scheduling)**
Flask REST API with a thread-safe FCFS scheduler that queues and dispatches orders across simulated virtual machines, exposing live waiting-time, response-time, and throughput metrics — configured for both serverless and WSGI deployment.
`Python` `Flask` `Threading` `Gunicorn`

#### Product

**[Personal Portfolio](https://github.com/saif098-bit/Portfolio)** · [live →](https://portfolio-six-plum-87.vercel.app)
Responsive Next.js portfolio with a custom animated hero, scroll-triggered reveals, and a Groq-powered chatbot that answers visitor questions from the site's own content.
`Next.js` `TypeScript` `Tailwind CSS` `Framer Motion` `Groq API`
