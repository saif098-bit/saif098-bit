### 🛠️ Featured Projects

**[Smart Medicine Inventory System](https://github.com/saif098-bit/smart-medicine-system)**
Full-stack pharmacy inventory PWA with real-time low-stock/expiry dashboards, an AI assistant chatbot (OpenAI + Groq fallback), and DSA-based visualizations for undo history and stock alerts.
`Python` `Flask` `SQLAlchemy` `SQLite` `OpenAI` `Groq`

**[Smart Attendance Management System](https://github.com/saif098-bit/Smart-Attendance-System)**
Role-based (admin/teacher/student) attendance platform with Flask-Login auth, automated 75% eligibility enforcement, and auto-generated Excel/Matplotlib reports.
`Python` `Flask` `PostgreSQL` `Pandas` `Matplotlib`

**[AI Email Automation Agent](https://github.com/saif098-bit/AI-Email-Automation-Agent)**
Agentic n8n workflow that polls Gmail, classifies emails via a LangChain text classifier, and autonomously drafts replies with Groq's Llama 3.1 8B — validated against a test dataset before deployment.
`n8n` `Groq` `LangChain` `Google Sheets`

**[Cloud Order-Processing Simulator](https://github.com/saif098-bit/FCFS-Scheduling)**
Flask REST API simulating a thread-safe FCFS scheduler dispatching orders across virtual machines, with live waiting-time, response-time, and throughput metrics.
`Python` `Flask` `Threading` `Gunicorn`

**[AI Hotel Assistant Chatbot](https://github.com/saif098-bit/hotelbot)**
Flask chatbot answering hotel FAQs via fuzzy matching against a SQLite knowledge base, falling back to a locally hosted LLM (Ollama — Phi-3/Mistral).
`Python` `Flask` `SQLite` `Ollama`

**[Personal Portfolio Website](https://github.com/saif098-bit/Portfolio)**
Responsive Next.js portfolio with a custom animated hero, scroll-triggered reveals, and a Groq-powered AI chatbot answering visitor questions from the site's own content.
`Next.js` `TypeScript` `Tailwind CSS` `Framer Motion` `Groq API`
