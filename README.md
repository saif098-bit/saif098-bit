#### 02 · AI Email Automation Agent

**LLM-powered email classification and response workflow**

An n8n automation pipeline that monitors Gmail, classifies incoming messages as orders or inquiries, generates tailored responses with Groq, validates the model output, and routes the result back into Gmail.

**Engineering highlights**

- Groq **Llama 3.1 8B Instant** for response generation.
- JSON response validation before Gmail actions.
- Google Sheets evaluation pipeline for testing classifications and generated responses.
- Sanitized workflow export with credential separation.

**Stack:** `n8n` `Groq` `Llama 3.1 8B` `LangChain` `Gmail` `Google Sheets` `JavaScript`

[View repository →](https://github.com/saif098-bit/AI-Email-Automation-Agent)
